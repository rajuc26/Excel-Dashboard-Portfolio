# Excel Sales Dashboard

## Project Overview
This project is an interactive Sales Dashboard created using Microsoft Excel to analyze sales performance and present key business insights through charts and visualizations.

## Objectives
- Analyze overall sales performance.
- Track sales and revenue trends.
- Identify top-performing products and categories.
- Compare sales across regions and time periods.
- Support data-driven business decisions.

## Tools & Skills Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas
- Charts and data visualization
- Slicers and filters (if applicable)
- Data cleaning and formatting

## Dashboard Features
- Sales performance summary
- Revenue and sales trend analysis
- Product and category performance
- Region-wise sales analysis
- Interactive filtering (if applicable)

## Key Insights
The dashboard helps users identify sales trends, understand product performance, compare regional results, and monitor important sales metrics.

## How to Use
1. Download the Excel workbook from this repository.
2. Open it using Microsoft Excel.
3. Use the available filters or slicers to explore the sales data.
4. Review the charts and key performance indicators.
