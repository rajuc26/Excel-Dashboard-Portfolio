Employee Performance Dashboard – Excel

📊 Project Overview

This project focuses on analysing employee performance data and presenting key workforce insights through an interactive Excel dashboard.

The dashboard helps understand employee performance, productivity, departmental comparisons, attendance trends, and overall workforce metrics.

🎯 Project Objectives

Analyse employee performance across different departments.

Identify high-performing and low-performing employees.

Monitor employee productivity and attendance.

Compare performance across departments.

Present key HR metrics using interactive visualisations.

🛠️ Tools & Technologies

Microsoft Excel

Pivot Tables

Pivot Charts

Excel Formulas

Slicers

Conditional Formatting

Data Cleaning

📌 Key Performance Indicators (KPIs)

Total Employees

Average Performance Score

Average Attendance Rate

Total Departments

High Performers

Employee Productivity

📈 Dashboard Features

Department-wise employee performance analysis.

Employee performance ranking.

Attendance and productivity analysis.

Performance distribution across categories.

Interactive filters using Excel slicers.

KPI cards for quick business insights.
